# TC-003 — Invalid JSON Import

**Date:** 2026-10-12  
**Environment:** Linux Mint / Firefox  
**Test Type:** Negative Testing  
**Status:** FAIL

## Objective

Verify that the application safely handles invalid JSON backup files.

## Test Steps

1. Create a malformed JSON file.
2. Open Belyash Farm Web.
3. Select the JSON backup import function.
4. Import the malformed file.
5. Check whether an error message appears.
6. Check whether a new profile is created.
7. Verify that the existing farm remains accessible.

## Expected Result

The application rejects the malformed JSON, displays a clear error message and preserves existing user data.

## Actual Result

- No visible error message appeared.
- No new profile was created.
- The existing farm remained accessible.
- No visible data loss was observed.

## Conclusion

FAIL — The application did not provide clear user feedback when an invalid JSON file was selected. Existing game data remained accessible.
