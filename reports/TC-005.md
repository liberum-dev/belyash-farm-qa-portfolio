# TC-005 — Slow Network Simulation

**Date:** 2026-10-14  
**Application:** Belyash Farm Web  
**Environment:** Linux Mint / Firefox Developer Tools  
**Test Type:** Network / Functional  
**Status:** PASS

## Objective

Verify that the web application can load successfully under simulated Regular 3G network conditions.

## Preconditions

- Firefox Developer Tools is open.
- Disable Cache is enabled.
- Network throttling is set to Regular 3G.

## Test Steps

1. Open the application.
2. Open Developer Tools → Network.
3. Enable Disable Cache.
4. Select Regular 3G.
5. Reload the page.
6. Wait for the game main menu.
7. Inspect HTTP requests and record the network timing.

## Expected Result

The application loads its required resources without HTTP failures and displays the main menu.

## Actual Result

- HTTP requests: 9
- Successful responses: 9 (200 OK)
- HTTP failures: 0
- Transferred: 38.07 MB
- Network Finish: 6.75 minutes
- Main menu displayed successfully.

## Comparison

| Network Profile | Finish |
|---|---|
| Cached / No Throttling | 2.85 s |
| Disable Cache / No Throttling | 7.10 s |
| Disable Cache / Regular 3G | 405 s |

## Conclusion

PASS — The application loaded successfully under the simulated Regular 3G connection.

Loading took substantially longer than under an unrestricted connection.

The measurements represent individual test runs, not statistically reliable performance benchmarks.

Network Finish does not necessarily represent the exact time when the main menu became usable.
