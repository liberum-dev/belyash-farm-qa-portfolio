# TC-004 — Network Loading Without Cache

**Date:** 2026-10-13  
**Application:** Belyash Farm Web  
**Environment:** Linux Mint / Firefox Developer Tools  
**Test Type:** Network / Functional  
**Status:** PASS

## Objective

Verify that the web application loads required resources successfully with the browser HTTP cache disabled.

## Test Steps

1. Open the Belyash Farm Web application.
2. Open Firefox Developer Tools → Network.
3. Enable Disable Cache.
4. Keep No Throttling selected.
5. Reload the browser page.
6. Wait until the game main menu is displayed.
7. Inspect HTTP status codes and network activity.

## Expected Result

All essential game resources load successfully, with no HTTP request failures, and the application displays the main menu.

## Actual Result

- Requests: 9
- Successful HTTP responses: 9 (200 OK)
- Failed HTTP requests: 0
- Transferred: 38.07 MB
- Network Finish: 7.10 s
- Game main menu displayed successfully.

## Comparison

| Metric | Cache Enabled | Cache Disabled |
|---|---|---|
| Requests | 9 | 9 |
| Transferred | 0 B | 38.07 MB |
| Finish | 2.85 s | 7.10 s |

## Conclusion

PASS — All observed resources loaded successfully with Disable Cache enabled. No HTTP failures were observed.

The results are based on a single measured load for each cache condition. Additional runs are required for reliable performance comparison.
