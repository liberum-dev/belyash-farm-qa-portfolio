# TC-002 — JSON Backup / Restore

Status: PASS
Date: 2026-10-12
Application: Belyash Farm Web
Environment: Linux Mint / Firefox
Test Type: Functional / Data Persistence

## Objective
Verify that JSON backup export and import
correctly restore the saved farm state.

## Steps
1. Load a test farm.
2. Record the initial farm state.
3. Export a JSON backup.
4. Modify the farm state.
5. Import the previously exported JSON backup.
6. Verify that the original state is restored.
7. Reload the browser page.
8. Verify that the restored state persists.

## Expected Result
The imported JSON backup restores the
original farm state without data loss.

## Actual Result
The original farm state was restored.
After reloading the browser page,
the restored state remained available.

## Conclusion
PASS — JSON Backup / Restore works
in the tested scenario.

## Notes
Other browsers and corrupted backup files
have not yet been tested.
