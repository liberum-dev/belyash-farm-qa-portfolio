# BUG-002 — No Feedback on Invalid JSON Import

**Project:** Belyash Farm Web  
**Date:** 2026-10-12  
**Environment:** Linux Mint / Firefox  
**Test Type:** Negative Testing  
**Severity:** Low (provisional)  
**Priority:** To be determined  
**Status:** Reproduced

## Description

The application does not display a visible error message when the user selects a malformed JSON backup file for import.

## Preconditions

- Belyash Farm Web is running.
- An existing test farm is available.
- A malformed JSON file has been prepared.

## Steps to Reproduce

1. Open Belyash Farm Web.
2. Navigate to the JSON backup import function.
3. Select a malformed JSON file containing:

   `{"invalid_json":`

4. Observe the application's response.
5. Open the saved farms list.
6. Verify that the existing profile remains accessible.

## Expected Result

The application rejects the invalid JSON file, displays a clear error message and preserves existing save data.

## Actual Result

- No visible error message appeared.
- No new farm profile was created.
- Existing farm data remained accessible.
- The application continued operating.

## Reproducibility

Reproduced in 2 of 2 test attempts.

In both attempts:
- No visible error message appeared.
- No new farm profile was created.
- The existing farm remained accessible.
- The application continued operating.

## Impact

The user receives insufficient feedback when attempting to import an invalid backup file. This may create confusion about whether the import succeeded or failed.
