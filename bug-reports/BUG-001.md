# BUG-001 — BelyashSave interface error

Status: Reproduced
Severity: Low (provisional)
Priority: To be determined
Environment: Linux Mint / Firefox
Application: Belyash Farm Web

## Steps to Reproduce
1. Open the web application.
2. Open Firefox Developer Tools > Console.
3. Reload the page.
4. Observe console output.

## Expected Result
Required JavaScript interfaces initialize correctly.
Optional missing interfaces are handled without
unexpected errors.

## Actual Result
ERROR: No interface 'BelyashSave' registered.

## Reproducibility
2/2 observed during initial checks.
Also observed in a subsequent test.

## Impact
No visible loss of saved game progress.
Underlying cause remains unknown.
